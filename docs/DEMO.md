# 产品演示流程

默认打开正式业务工作空间，登录页面不显示模型配置或示例按钮。演示前由管理员接入真实 AI 服务，准备脱敏的两轮项目沟通；服务不可用时可通过手动新增需求走完整个版本流程。

## 演示前检查

- 按 [部署说明](../DEPLOY.md) 配置根目录 `.env` 并重启服务，不使用 `.env.txt`。
- 首次使用自行注册账号；没有默认账号，测试截图中的账号不随源码分发。
- 用脱敏材料实际验证智能整理能成功，再开始展示。健康接口成功不代表模型可用。
- 展示的数据应说明来源；浏览器测试截图与合成评测案例不代表真实客户试用。
- GitHub 发布的是源码与文档，不是已托管的在线服务；本地访问地址只在启动服务的机器上可用。

## 90 秒讲解

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0–15 秒 | 登录、新建项目，查看概览并添加沟通材料 | 项目资料统一归档，概览来自实际记录 |
| 15–35 秒 | 智能整理或手动新增需求，展开原文依据并确认 V1 | 来源可追溯，正式内容经过人工审核 |
| 35–55 秒 | 单独勾选第二轮沟通，与正式版本比较 | 区分范围变化、明确排除和待定问题 |
| 55–75 秒 | 逐条审核并提交变更 | 稳定需求 ID 保留需求的演变，未变化不会制造空版本 |
| 75–90 秒 | 查看版本对比、导出文档，回到概览 | 历史快照保留，材料、版本和工作事项连贯 |

开场可表述：“需记是一个项目需求协作工作空间，将客户沟通、正式需求和范围变更组织在同一个流程里。”

如果没有真实智能服务，使用手动新增和基线修订演示，说明当前使用的是人工整理路径，不把固定结果声称为模型能力。

## 培训环境

仅为操作演练需要时，在独立部署中显式设置 `ENABLE_DEMO_MODE=true`，访问 `/?training=1`。此入口标为培训演练空间，固定结果不代表真实模型效果；正式环境保持 false。登录页和业务导航不显示培训入口。

浏览器回归测试使用本地模型协议替身，验证 HTTP 调用与业务状态，不作为真实模型效果证明。实际界面截图位于 `docs/screenshots/`；录制视频前应脱敏客户资料。
